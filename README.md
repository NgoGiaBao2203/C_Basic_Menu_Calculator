# C Basic Menu Calculator

A simple console application written in C that includes a calculator and an array manager.

---

## Features

### 1. Calculator
* Add (`+`), Subtract (`-`), Multiply (`*`), and Divide (`/`) two numbers.
* Safe division (prevents dividing by zero).

### 2. Array Calculator
* Create an array with random numbers based on a size you choose.
* Search for items inside the array.
* Sort the array in Ascending (low to high) or Descending (high to low) order.
